# Kahyrah Product Page Translation Review

**Version 2.0 --- Final Review Baseline** \> This document consolidates
the approved English/French copy for the Kahyrah Product page. It
preserves the review structure: **UI Element \| English (Current) \|
French (Current) \| English (Approved) \| French (Approved) \| Notes**.
\## Editorial and Brand Rules - **Kahyrah** = company → designs and
develops software solutions. - **Council Revenue Platform** = product →
manages council revenue operations. - French capability descriptions use
the **infinitive convention**: *Vérifier / Suivre / Permettre /
Maintenir / Rapprocher...* rather than imperative forms. - Product
naming and company/product distinctions follow the approved review
baseline.
