## Section 3 — Pilot Workflow

This is the section we redesigned visually, so the French needs to work well inside the new workflow cards.

| UI Element | English — Approved | French — Proposed |
| --- | --- | --- |
| Eyebrow | Pilot Workflow | DÉROULEMENT DU PILOTE |
| Heading | A clear path from pilot definition to evidence | Un parcours clair, de la définition du pilote aux résultats concrets |
| Description | Each stage produces a tangible outcome, keeping the pilot focused and easy to evaluate. | Chaque étape produit un résultat concret, permettant de maintenir un pilote ciblé et facile à évaluer. |
| Step 1 | Pilot scope confirmation | Confirmation du périmètre du pilote |
| Step 1 description | Confirm the council’s operating context, pilot objectives, success criteria and agreed operating scope. | Confirmer le contexte opérationnel de la collectivité, les objectifs du pilote, les critères de réussite et le périmètre opérationnel convenu. |
| Step 2 | Council data onboarding | Intégration des données de la collectivité |
| Step 2 description | Prepare selected areas, places, merchants and users through a structured onboarding workbook. | Préparer les zones, emplacements, commerçants et utilisateurs sélectionnés à l’aide kit d’intégration structuré. |
| Step 3 | Pilot configuration | Configuration du pilote |
| Step 3 description | Configure roles, operating areas, expected charges and the workflows the pilot will exercise. | Configurer les rôles, les zones opérationnelles, les montants attendus et les processus qui seront mis en œuvre pendant le pilote. |
| Step 4 | QR card preparation | Préparation des cartes QR |
| Step 4 description | Generate and prepare merchant QR cards for the selected pilot locations. | Générer et préparer les cartes QR des commerçants pour les emplacements sélectionnés dans le cadre du pilote. |
| Step 5 | Team training | Formation des équipes |
| Step 5 description | Run focused sessions for field agents and supervisors using realistic daily scenarios. | Organiser des sessions ciblées pour les agents de terrain et les superviseurs à partir de scénarios quotidiens réalistes. |
| Step 6 | Daily monitoring | Suivi quotidien |
| Step 6 description | Review adoption, alerts, collection activity and operational gaps throughout the pilot. | Suivre l’adoption, les alertes, l’activité de collecte et les écarts opérationnels tout au long du pilote. |
| Step 7 | Final pilot review | Revue finale du pilote |
| Step 7 description | Assess outcomes, capture learning and define the most sensible next phase. | Évaluer les résultats, tirer les enseignements du pilote et définir la suite la plus appropriée. |

This reflects the important approved English change from Discovery call to Pilot scope confirmation, ensuring that the pilot workflow no longer duplicates the pre-pilot discovery/demo journey.

One deliberate translation choice here is “résultats concrets” for evidence in the heading. I would avoid the literal “preuves”, which sounds awkward in this commercial/operational context. The detailed evidence methodology can use more precise terminology when appropriate.

## Section 4 — Evidence Over Promises

| UI Element | English — Approved | French — Proposed |
| --- | --- | --- |
| Eyebrow | Evidence Over Promises | DES RÉSULTATS CONCRETS, AU-DELÀ DES PROMESSES |
| Heading | Finish with a shared view of what worked | Terminez avec une vision partagée de ce qui a fonctionné |
| Description | The final review brings together operational observations, platform activity and feedback from agents and supervisors—giving decision-makers a practical basis for deciding what comes next. | La revue finale rassemble les observations opérationnelles, l’activité de la plateforme ainsi que les retours des agents et des superviseurs, offrant aux décideurs une base concrète pour déterminer la suite à donner. |

The final English wording deliberately changed from “a practical basis for the next step” to “a practical basis for deciding what comes next.”

I particularly like « Des résultats concrets, au-delà des promesses » here. A literal translation such as « Des preuves plutôt que des promesses » would be grammatically valid but less natural for the tone of the French website.
